Etiquetas HTML más utilizadas
Etiqueta Descripción
<h1> Encabezado de nivel 1
<p> Párrafo de texto
<table> Tabla de datos
<caption> Título de la tabla
<tr> Fila de la tabla
<th> Encabezado de columna
<td> Celda de datos
<marquee> Texto en movimiento
<aside> Contenido adicional o complementario
<footer> Pie de página
<header> Encabezado de la página
<i> Texto en cursiva
<b> Texto en negrita
<mark> Texto resaltado
<details> Elemento interactivo que muestra u oculta contenido adicional
<summary> Elemento que define un resumen o título para el contenido adicional dentro de <details>
<img> Etiqueta para insertar imágenes
<hr> Etiqueta para insertar una línea horizontal
<form> Etiqueta para crear formularios
<input> Etiqueta para crear campos de entrada en formularios
<CSS> Etiqueta para insertar estilo CSS
<JavaScript> Etiqueta para insertar código JavaScript
<defer> Etiqueta para retrasar la carga del Script hasta que la pagina este cargada
<Let> Etiqueta para declarar variables locales en JavaScript, Solo usar eso, var ya no es necesario
<const> Etiqueta para declarar variables constantes en JavaScript, es decir, su valor no puede ser reasignado después de su declaración
<document> Etiqueta para representar el documento HTML
<document.getElementById> Etiqueta para obtener un elemento del documento HTML por su ID
<document.getElementsByClassName> Etiqueta para obtener elementos del documento HTML por su clase
<document.querySelector> Etiqueta para obtener un elemento del documento HTML por su selector, remplaza a los 2 anteriores
<document.addEventListener> Etiqueta para agregar un evento a un elemento del documento HTML

Información adicional

HTML es el lenguaje de marcado utilizado para crear páginas web. Es fundamental para el desarrollo web y se utiliza junto con CSS y JavaScript para crear sitios web interactivos y atractivos.

Más sobre HTML

HTML significa HyperText Markup Language. Fue creado por Tim Berners-Lee en 1991 y ha evolucionado a lo largo de los años para incluir nuevas etiquetas y características que permiten a los desarrolladores web crear contenido más rico y dinámico.
